# 🎯 PrepWise AI

PrepWise AI is a web application that helps job seekers practice for real job interviews using AI voice agents. 

You can select a job role (e.g. *Frontend Developer*, *Full Stack Engineer*), experience level, and tech stack. An AI interviewer will conduct a live voice interview with you and give you instant detailed feedback on your performance.

---

## ⚡ Features

- **🎙️ Real-Time Voice Interview**: Talk directly with an AI interviewer using voice streaming powered by Vapi AI.
- **🎯 Tailored Questions**: Questions are dynamically generated based on your chosen job role and tech stack using Google Gemini AI.
- **📊 Instant Feedback**: Get scored on Communication, Technical Knowledge, Problem Solving, Cultural Fit, and Confidence.
- **🔐 User Accounts**: Sign up and track your past interviews and scores over time.

---

## 🛠️ Tech Stack

- **Frontend & Backend**: Next.js 15, React 19, Tailwind CSS
- **AI & Voice**: Vapi AI (Voice Streaming), Google Gemini 2.0 (AI Generation)
- **Database & Auth**: Firebase Authentication, Cloud Firestore
- **Hosting**: Render

---

## 🚀 How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/ATHARVA-THAKAR/prepwise-ai-interview.git
   cd prepwise-ai-interview
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Set up environment variables**:
   Create a `.env.local` file in the root folder with your Firebase, Vapi AI, and Google Gemini API keys.

4. **Start the app**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
